The personal homepage links to the course site, and the course navigation links back to the personal homepage. Both sites also link to the university and GitHub Pages versions.

To publish the corrections, deploy this repository’s contents to GitHub Pages and upload the same contents to the university webspace. Keep `index.html` at the webspace root and `itis3135/index.html` inside the `itis3135` folder. Upload the course `components` folder as well so the shared navigation loads.
